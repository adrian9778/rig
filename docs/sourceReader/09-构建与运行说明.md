# 09-构建与运行说明

本章提供了 Rig 项目的编译、测试、运行及部署相关说明，旨在帮助开发者快速上手整个项目生命周期。

---

## 🧰 环境准备

### 1. Rust 工具链 (Minimum supported version: 1.70)
Rig 基于现代 Rust 开发，使用 Cargo 来管理依赖和构建过程。
若尚未安装，请前往 [https://rustup.rs](https://rustup.rs) 安装 rustup 及默认工具链。

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

验证安装：

```bash
rustc --version
cargo --version
```

### 2. Git 和目标架构支持

确保已克隆项目代码，并启用了 Wasm 支持（如果计划用于 Web 环境）：
```bash
git clone https://github.com/your-project/rig.git
cd rig
rustup target add wasm32-unknown-unknown
```

---

## 🧱 构建流程

### 1. 标准构建

```bash
cargo build
```

若需要构建 Release 版本（优化性能）：

```bash
cargo build --release
```

### 2. 使用 Feature Flag 控制组件

Rig 模块化较高，可以通过 Cargo 的 features 来启用特定 Provider 或向量数据库支持：

#### 示例：启用 OpenAI 和 Qdrant 支持

```bash
cargo build --features openai,qdrant
```

> 所有 crate feature 可在 `Cargo.toml` 中查看定义。

### 3. WebAssembly 构建（可选）

对于需要运行在浏览器中的应用，可以将 Rig 编译为 WASM：

```bash
cargo +nightly build --target wasm32-unknown-unknown --lib
```

## 🧪 测试执行方式

Rig 提供多个测试层级：
- 单元测试（unit tests）
- 集成测试（integration tests）
- Cassette 录制回放（mocked API）

### 1. 执行单元测试

```bash
cargo test
```

### 2. 指定模块测试

```bash
# 对某个 Provider 做测试
cargo test -p rig-openai openai::cassette

# 或者指定一个 crate 下所有的测试（不加参数）
cargo test -p rig-agent
```

### 3. 录制与回放 Cassette 测试

Cassette 测试用于模拟真实 API 请求响应，避免每次运行都调用远程服务。

#### 回放模式（推荐）
默认启用：

```bash
cargo test
```

#### 录制模式（更新 fixture）：
```bash
RIG_PROVIDER_TEST_MODE=record cargo test -p rig-openai openai::cassette -- --nocapture
```

> 注意：录制前确认已配置 API Key（如 OPENAI_API_KEY）

## 🚀 示例运行

### 示例 1：启动一个基础 Agent 示例

```bash
cargo run -p rig-agent --example basic_chat_agent
```

### 示例 2：使用 OpenAI 构建一个工具型 Agent

```bash
cargo run -p rig-openai --example tool_using_agent
```

> 示例位置位于 `examples/` 或每个 crate 内的 `examples/` 路径下。

## 🔧 开发辅助配置

### 1. 使用 Clippy 检查编码规范

```bash
cargo clippy --all-targets --all-features
```

### 2. 自动格式化代码

使用 rustfmt：

```bash
cargo fmt
```

### 3. 编写文档

构建 doc：

```bash
cargo doc --workspace --no-deps
```

## 📦 发布与部署（适用于最终发布）

### 配置 Cargo.toml 发布元信息（仅用于 crates）

编辑 `Cargo.toml` 文件并添加如下字段：

```toml
[package]
name = "your-lib-name"
version = "0.1.0"
edition = "2021"

# ... 其他配置 ...

[dependencies]
rig-core = { version = "^0.1", features = ["openai"] }
rig-agent = "^0.1"
```

### 发布到 Crates.io

```bash
cargo login
cargo publish
```

> 确保已注册账户，并检查版本号无冲突。

## 🛠️ 项目结构说明（重要路径）

| 路径 | 说明 |
|------|------|
| `src/`, `crates/*/src/` | 核心源码目录 |
| `examples/`, `crates/*/examples/` | 示例程序入口 |
| `tests/`, `crates/*/tests/` | 测试文件，包括 cassette 和单元测试 |
| `docs/sourceReader/` | 本手册存放位置 |
| `Cargo.toml` | 主项目配置 |

## 🧩 总结

Rig 工具链涵盖了从开发到生产环境的全流程支持。开发者可通过标准 Cargo 命令高效完成本地调试与持续集成流程，并借助以下方式保障代码质量和稳定性：

- 结构化的测试套件和 mock 机制（cassette）
- 明确的功能 feature 机制
- 完整的文档构建工具链

这些特性使 Rig 成为一个易于开发、维护且可扩展的强大 AI 应用构建平台。
